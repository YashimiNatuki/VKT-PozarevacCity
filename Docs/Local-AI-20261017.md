# Local contact stories / Ollama

VKT now has three contacts in **L / BLOK / LIK > KONTAKTI / OLLAMA**. The screen opens immediately with authored offline dialogue. Choose Mila, Vuk or Luka, then **OSVEŽI / OLLAMA** or **SAVET ZA LIKA**. **PRATI CILJ** opens the existing journal for jobs/delivery, the lifestyle menu for food, or returns to the current objective. ESC closes the screen and restores gameplay.

## What controls the game

Unity decides the next action from current state in this order: heat at least 30, nutrition below 20, stamina below 30, incomplete campaign, active street job, available jobs. Both sides implement this policy; Unity validates the action and displays its own objective. AI generates only one short dialogue sentence. Contact headings and practical tips are authored. It cannot award money, complete a mission, change a save, execute code or issue commands.

The source label is explicit: **OLLAMA** means a validated generated sentence; **KEŠ** means a previously generated local sentence; **OFFLINE PRIČA** means authored fallback. This is a bounded narrative prototype. A small model can still produce awkward Serbian; automated checks are not a human language-quality guarantee. No voice synthesis or multiplayer server is added in this wave.

## Start the optional backend on Windows

The game works without the service. To enable generation, install Python 3.12+ and Ollama, with a local model already installed. The checked machine uses `llama3.2:3b`. The service never downloads models. Model weights retain their provider's license; first-party MIT licensing does not replace it.

From the repository root (or the extracted ZIP, which includes `LocalAI`):

```powershell
# Repository path; in the ZIP use .\LocalAI\Start-LocalAI.ps1 instead.
powershell -File .\Tools\LocalAI\Start-LocalAI.ps1 -Prepare
# Later runs reuse the isolated runtime and do not install anything:
powershell -File .\Tools\LocalAI\Start-LocalAI.ps1
```

`-Python 'C:\Path\To\python.exe'` selects Python for initial preparation. `-Background` starts a hidden process; the printed PID identifies that process. Foreground Ctrl+C stops the service. No startup task, firewall opening or paid account is configured. Use one process on port 18741. The default isolated Python runtime is under `%LOCALAPPDATA%\VKTLocalAI\runtime`; dependencies are pinned in `requirements.txt`.

Backend health: `http://127.0.0.1:18741/health`. `warm_status=ready` means the model preload request completed, not that every future reply will pass validation. Preload has a 45-second bound. First cold startup can take tens of seconds on this machine. Unity waits at most 40 seconds for a request; backend total deadline is 35 seconds. Menus can be closed while waiting. Model unloading, insufficient resources, bad text, timeout or an unavailable service produce authored fallback.

## Boundaries and scaling

- FastAPI/Pydantic validate a fixed facts schema. There is no freeform prompt input, personal identity, save-file transfer or credential.
- Uvicorn binds `127.0.0.1:18741`, one worker; outbound model calls go only to `127.0.0.1:11434`, ignoring environment proxies. Browser Origin and foreign Host headers are rejected. This is a local companion, not a network security boundary against other local processes.
- One generation at a time avoids model overload. A sliding 60-second window permits 12 uncached attempts. A busy worker returns fallback immediately. Three generation failures open a 60-second circuit.
- Cache keys hash model, prompt revision, contact, intent, chapter, campaign, quantized vitals, job state and authoritative action. SQLite WAL retains at most 256 generated entries for three hours. Cache lookup bypasses generation limits. A corrupt existing file is preserved and an in-memory cache is used instead.
- Private cache: `%LOCALAPPDATA%\VKTLocalAI\story.sqlite3`. No database, virtual environment or model weights are included in source or release archives. Health counters contain counts rather than dialogue logs.
- Only a validated single sentence is accepted; metadata-only text, numbers, URLs, markup, oversized or context-free replies are rejected. These checks reduce bad responses but do not guarantee factual or literary quality.
- Android currently uses authored offline contacts. Desktop loopback does not reach a PC from a phone. No new APK, remote API or cloud deployment is claimed here.

## Verification and next work

Run backend checks with `python -m pytest Tools/LocalAI/test_backend.py -q` in the prepared environment. Unity EditMode includes contact action priority and hostile response checks. The Windows smoke path `-vktLifeSmoke -vktCharacterSmoke -vktLocalAiSmoke` exercises the actual UI, cancellation, pause ownership and unchanged mission/cash state. `-vktLocalAiRequired` requires a generated/cached response instead of accepting fallback. The final receipt records actual results and the downloadable ZIP hash.

Next: a reviewed Serbian dialogue corpus and character-specific vocabulary, a stronger optional local model benchmark on this hardware, and a rights-cleared Serbian TTS pipeline with listening tests. Then physical Android verification and portable local-only packaging. The current model is an optional text layer, not a replacement for authored mission logic.

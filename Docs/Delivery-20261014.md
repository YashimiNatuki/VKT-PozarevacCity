## Saves

Normal profiles are stored under Application.persistentDataPath/vkt-profile-v1.json. Batch and -vktSmoke validations use separate temporary profiles.

The current schema persists completed contracts, balances, callsign, inventory, remaining plot time, crew and block counts. An unfinished mission restarts at pickup without reward. Growth does not advance while the game is closed.

SHA-256 checks corruption, not owner tampering or encryption. An exclusive file gate plus fingerprint rejects stale concurrent saves. Damaged and backup copies are preserved during recovery. Unknown/newer or unrecoverable profiles block automatic writes.

# Botanical illustration provenance

`Assets/CityGame/Resources/Art/BotanicalAtlas.png` is one original AI-generated atlas created for VKT on 2026-10-14 using the built-in image generation tool. It is not a photograph, authenticated cultivar record or copied internet plant photo.

Reading order is two columns by four rows: lavender, basil, spearmint, rosemary, sage, African marigold, purple coneflower, lemon balm. The eight fictional game varieties use these as explicitly labeled botanical analogues. Species cards retain primary NC State Extension Plant Toolbox source links for factual descriptions. Entries 8–15 are informational and have no illustration yet.

The game uses UV rectangles directly; it does not modify the generated pixels. Atlas framing, natural plant forms and UI legibility require visual review. No personal music, model weights or external stock photography accompanies the atlas.
## Facade atlas

CityFacades.png is an original AI-generated two-by-two facade texture atlas created for VKT on 2026-10-15. It depicts an authored Central Serbian historic-town architectural style, not photographs or surveyed facades of specific Požarevac buildings. Four variants map onto actual OSM perimeters; window placement, surface colors and facade proportions are artwork. The runtime partitions wall spans into bounded texture sections and uses separate plain roofs. The original generated pixels are preserved.

## Gameplay changes

- Phone journal now exposes offer details, route steps, reward, deadline, accept and cancel controls. Accepting through the actual UI closes the phone and releases overlay pause before starting the route.
- Repeatable street jobs use three physical station visits. Payment is awarded only after route completion; the runtime check rejects duplicate payout.
- Save schema v4 reads older schemas 1–3 and persists completed-job count with cash/reputation in the same profile snapshot. Completed story progress survives reload. Active routes and cooldown deliberately reset on reload without awarding a reward.
- OSM-derived streets retain 40 building footprints and **397 wall colliders**, with visible **2.4 × 2.5** doorway passages. This is an authored gameplay prototype, not proof of architectural or full-city geographic accuracy.

BEZBEDNOSNI CIKLUS
Svih osam početnih Dependabot upozorenja je iz opcionog VITS development
manifest-a: Transformers 4.57.6 i Torch 2.8.0; 4 high, 2 moderate, 2 low.
Ove biblioteke nisu ugrađene u Windows EXE ili Android APK.
Coqui 0.27.5 ima nekompatibilne eager XTTS importe sa novijim Transformers
paketom. Brisanje direktnog pin-a ne uklanja transitive dependency.
Blind upgrade ili forsiranje neusklađenih Torch/Torchaudio binarnih paketa
nije profesionalna ispravka.

Uz korisnikovu saglasnost povučen je aktivni VITS installation manifest i
Coqui/Torch izvršavanje iz javnog generatora. Legacy komanda odbija sintezu
pre importa model runtime-a i pre kreiranja WAV izlaza. --check-model ostaje
read-only provera četiri ranije pregledana fajla preko veličine i SHA256.
To nije zakrpa starih biblioteka niti tvrdnja da je model bezbedan ili prirodan.
Modeli, svi postojeći WAV-ovi i Git istorija su očuvani. Staro lokalno okruženje
ostaje izdvojeno za kontrolisano istraživanje; nije globalno deinstalirano.
Piper i uvoz pregledanih snimaka ostaju dostupni. Nijedan novi glas nije odobren.
GitHub status se proverava posle push-a, bez dismiss-a ili suppress-a upozorenja.

VKT THUG LIFE STUDIO — LOKALNI PLUGIN 0.1.2
ID: yashimi-vkt-studio@yashimi-vkt-local
Tri skilla i lokalni Python helperi; nema novog servera, remote privilegija,
plaćenog modela ili Unity runtime modula.

$vkt-thuglife-engineer
Povezani CityGame gameplay, misije, policija, trening, save i UX. Čuva
payout-once i ownership pauze/inputa/audio resursa. Windows je prvi cilj.

$vkt-world-asset-review
Pregled glave/skeleta/mimike, modela, kolizija, terena, koordinata, visina,
licenci i zvuka pre Unity uvoza. Ne zamenjuje fizičku/humanu vizuelnu proveru.

$vkt-release-verifier
Poredi XML rezultate, bajtove paketa i deklarisani fingerprint. Stari VKT
fingerprint pokriva samo izabrane CityGame ekstenzije, ne sve build ulaze.
Helper izričito vraća completeBuildInputBinding=false i releaseApprovalReady=false.
XML identitet je potvrđen samo ako receipt ima testsSha256; isti broj testova
nije dokaz istog run-a. Novi produkcioni gate traži potpun build input manifest.

Izvor: Tools/VktStudio/marketplace/plugins/yashimi-vkt-studio

Paket: VKT-Thug-Life-Studio-0.1.2.zip — jedan plugin u root-u ZIP-a.
Plugin je lokalno instaliran/uključen; nova Codex sesija možda treba da otkrije
skill chip-ove. Nisu izmišljeni MCP alati niti cloud aktivacija.

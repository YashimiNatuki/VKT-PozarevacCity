# Third-party notices and distribution boundary

The root MIT license covers first-party VKT source, tools and documentation. It does not relicense Unity, restored packages, map services or external content.

- **Unity Editor/runtime and Unity packages:** retain Unity and package-specific terms. Unity is not made open source by this repository. Restore packages through Unity; review each resolved package license for redistribution.
- **Cesium for Unity 1.26.0:** package restored from the Cesium scoped registry; retain its package license and notices. Cesium ion, Google map tiles and other streamed data have separate service/content terms. The exported offline fixture contains no original map scene or service credentials.
- **ArcGIS Maps SDK 2.4.0 and Unity Starter Assets:** excluded from the clean source export. Their original vendor licenses are not replaced by MIT.
- **Existing Footstep/Land recordings:** excluded from the export because redistribution provenance has not been established. The game tolerates missing optional effects.
- **Generated synthetic ambience:** generated by first-party runtime code; it is not an authentic recording of Požarevac.
- **OpenStreetMap-derived streets:** `Assets/CityGame/Resources/Maps/PozarevacStreets.json` contains derived street segments attributed to **© OpenStreetMap contributors**, available under the [Open Database License (ODbL)](https://www.openstreetmap.org/copyright). Preserve attribution, provenance and applicable database share-alike obligations when distributing/modifying this dataset. ODbL applies to that database, not automatically to independent first-party game code. The root MIT license does not replace the dataset's license.
- **Piper:** the optional offline authoring tool invokes a separately installed engine; no engine or model weights are bundled. Current Piper uses GPL-3.0. Voice/dataset terms must be reviewed independently.
- **Serbian serbski_institut Piper candidate:** its model card lists a two-speaker dataset under CC BY-NC-SA 4.0. The umbrella repository MIT label does not override that restriction. No clips from this model are shipped or asserted as commercially cleared.

No natural Serbian actor recordings, HeyGen output, third-party video, downloaded city sound libraries or model weights are included in this source milestone. Future additions need a per-asset source, license, author and modification record before publication.
